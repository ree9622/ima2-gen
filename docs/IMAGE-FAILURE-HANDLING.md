# 이미지 생성 실패 처리

2026-11-09 운영 기록과 같은 호출 경로를 확인했습니다.

- 안전 시스템 거절은 첫 응답에서 `SAFETY_REFUSAL`로 종료합니다. 자동 재시도·프롬프트 변형·다듬기를 실행하지 않습니다. 원문 오류와 요청 식별값은 지원 문의를 위해 보존합니다.
- `all codex accounts busy`는 안전 거절이나 월간 한도 초과가 아닙니다. 중계 서버가 최대 60초 기다린 뒤 보내는 용량 부족입니다. 추가로 8초 기다려 같은 요청을 한 번만 재시도하며, 계속 사용 중이면 `UPSTREAM_BUSY`와 503으로 종료합니다. 새 대기 작업도 이 시간 동안 시작하지 않습니다.
- 네트워크·분당 한도·인증·월간 한도 처리는 기존 분기를 유지합니다. 이유 요약만 있고 이미지가 없는 응답은 명시적 거절로 단정하지 않습니다.
- 실패 상세는 예전 `ALL_ATTEMPTS_FAILED` 기록의 오류 문구도 읽어 안전 거절과 계정 포화를 설명합니다. 과거 원본 기록은 수정하지 않습니다.
- 현재 코덱스 구독의 Images 경로에는 `moderation` 요청값을 보내지 않습니다. 출력 WebP/JPEG는 서버가 PNG를 변환합니다. 모더레이션 선택이나 파일 형식을 바꿔 안전 거절을 해결할 수는 없습니다.
- 실제 이미지 모델 버전은 중계 응답에서 제공되지 않을 수 있습니다. 요청 모델명과 실제 버전 확인은 [모델 확인 문서](CODEX-IMAGE-MODELS.md)를 따릅니다.

검증은 실제 재시도 함수를 모의 응답으로 실행하는 `tests/safety-refusal-stop.test.js`와 Images 요청 계약 검사를 사용합니다. 거절된 원본 요청을 다시 생성하거나 계정·안전 제한을 변경하지 않습니다.
